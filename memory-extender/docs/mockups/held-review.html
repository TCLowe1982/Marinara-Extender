Notes for the build

  • Reads reconcile-queue/held.jsonl, filtered to records whose reasons include discarded-swipe. No new storage.
  • Plain-language reasons are rendered from the closed vocabulary (recited:N, retrieved:N, thread:ID, orphans:ID) — the surface is readable, the underlying values stay countable.
  • “Restore the older memory” is restoreSupersededEntry, which already exists.
  • “Bring this one back” needs a restoreDiscardedEntry — the one piece of storage still missing. Mirror restoreDeletedEntry, guarded to discardedAt rows so it can never resurrect a superseded or user-deleted entry.
  • “Leave it retired” only clears the record from the lane. The memory is already retired; this is an acknowledgement, not a mutation.
  • Held records have no removal path yet — held.jsonl is append-only. Dismissing needs one.
